# router-ssh

Утилита запускается на компьютере администратора и использует системный клиент OpenSSH. Собрать её можно командой `cargo build --release --locked -p router-ssh`.

Адрес и пароль задаются через `ROUTER_HOST` и `ROUTER_PASS`. По умолчанию используются порт 222 и пользователь `root`. Их можно изменить через `ROUTER_PORT` и `ROUTER_USER`. Явно указанные параметры соединения имеют приоритет над окружением.

```sh
router-ssh exec --timeout 15s 'uptime'
router-ssh diagnose --only system,routing
router-ssh upload --mode 0644 local.txt /tmp/remote.txt
router-ssh download /tmp/remote.txt local-copy.txt
```

OpenSSH сохраняет ключ при первом подключении и прерывает соединение, если ключ изменился. Для отдельного файла доверенных ключей задайте `ROUTER_KNOWN_HOSTS`. Пароль поступает клиенту через `SSH_ASKPASS`. При выборе `--password` сама командная строка вызывающей оболочки содержит пароль.

При передаче файлы записываются во временный файл и переименовываются после успешного завершения. Команда `diagnose` выполняет выбранные разделы в фиксированном порядке и возвращает первую ошибку после выполнения остальных проверок.

Запуск локальных тестов — `cargo test --locked -p router-ssh`.
