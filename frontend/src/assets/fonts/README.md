Inter variable font, version 5.3.0 from `@fontsource-variable/inter`.

Source: https://registry.npmjs.org/@fontsource-variable/inter/-/inter-5.3.0.tgz

Only Latin and Cyrillic upright variable-weight subsets are bundled. Vite embeds
these WOFF2 files in the single HTML artifact; the router UI makes no external
font requests. Other scripts use the system font fallback.
